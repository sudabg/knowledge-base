# 🔍 问题模式库 (Problem Patterns)

> 识别模式 = 预防问题。同一个坑不踩第二次。

---

## 模式索引

### P-001 | 盲目乐观症 (Blind Optimism)
- **症状**: "改好了"、"完成了"、"没问题"——但没有验证数据
- **频率**: 高（几乎每天）
- **根因**: 完成感带来的多巴胺让人跳过验证
- **反模式**: 说完成就验
- **对策**: 每次声称完成前，必须输出验证命令的结果
- **示例**: "skill_router.py 已创建并测试通过 ✅" → 验证：`python3 scripts/skill_router.py "飞书" && python3 scripts/skill_router.py "非匹配" && python3 -m py_compile scripts/skill_router.py && echo "✅ 验证通过"`
- **状态**: 🟡 部分缓解

### P-002 | 路径依赖 (Path Dependence)
- **症状**: "没 token=不能做"、"API 限流=等"——从不搜替代方案
- **频率**: 中
- **根因**: 已知方法形成认知锚点，替代方案不可见
- **反模式**: 遇到限制就等
- **对策**: 卡住 15 分钟后触发搜索协议：搜索 CLI 工具、开源 wrapper、browser automation
- **示例**: "Twitter 发推需要 API token" → 应该搜 "twitter CLI tool NodeJS"
- **状态**: 🟡 已有一次正面案例

### P-003 | 工作碎片化 (Work Fragmentation)
- **症状**: 同时开 5 个大任务，每个做了一半
- **频率**: 高
- **根因**: 一条明经常在 session 里并发多个任务
- **反模式**: 全部 parallel 一起跑
- **对策**: 主动问优先级，或者自己用 Stack 排序（紧急×重要×可完成性）
- **示例**: Harness + Hermes + Dashboard + EvoMap 同时进行
- **状态**: 🔴 未改善

### P-004 | 记录冗余 (Record Bloat)
- **症状**: .learnings/ 文件堆积，pending capsule 越来越多
- **频率**: 中
- **根因**: 只写不清理
- **反模式**: 每次新增文件但不清理旧文件
- **对策**: 每周清理一次，30 天前的低价值文件删除
- **示例**: pending_capsule 文件积压 3 个以上
- **状态**: 🔴 未改善

### P-005 | 验证幻觉 (Validation Illusion)
- **症状**: 跑了测试但测试本身有 bug，或者测试覆盖不全
- **频率**: 中
- **根因**: 测试代码也是我写的，天然有盲区
- **反模式**: 只跑自己的测试
- **对策**: 用独立评估者（Mode 11）或让一条明做验收
- **示例**: Dashboard 测试通过但 API 返回空——测试没覆盖端到端
- **状态**: 🟡 有对策但执行不一致

### P-006 | 优先级模糊 (Priority Ambiguity)
- **症状**: 不知道该先做什么，所有任务看起来同等重要
- **频率**: 高
- **根因**: 一条明给任务时不带优先级，我也不主动问
- **反模式**: 按时间顺序处理（先到先做）
- **对策**: 问"这 3 个任务你最想先看到哪个的成果？"
- **示例**: "帮我看 Harness、顺便清 skills、另外 EvoMap 也看看"
- **状态**: 🔴 未改善

### P-007 | 孤立进化 (Isolated Evolution)
- **症状**: 进化完全发生在自己的小盒子里，不知道外界在做什么
- **频率**: 持续
- **根因**: 没有参与社区，没有关注上游动态
- **反模式**: 只在自己的 workspace 里转圈
- **对策**: 每周查看 OpenClaw GitHub issues/PRs，参与有意义的讨论
- **示例**: 不知道 OpenClaw 最近加了什么功能、修了什么 bug
- **状态**: 🔴 未改善

### P-008 | 反馈延迟依赖 (Feedback Latency Dependency)
- **症状**: 卡在问题上等一条明回复，几小时浪费
- **频率**: 中
- **根因**: 默认等待模式而非主动切换
- **反模式**: 等死
- **对策**: 15 分钟超时自动切换任务
- **示例**: 等飞书文件链接的正确格式等了几小时
- **状态**: 🟡 已有规则但未自动执行

## 使用方式

遇到问题时：
1. 先搜 patterns.md，看是否匹配已有模式
2. 匹配 → 应用对策，记录"又犯了 P-XXX"
3. 不匹配 → 新建模式条目
4. 模式被确认 3 次以上 → 升级为 AGENTS.md 中的硬规则
