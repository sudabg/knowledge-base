# 平台级限制声明（2026-04-02）

## 不可突破的天花板
1. Cron 调度依赖 OpenClaw gateway。gateway 挂 = 所有 cron 停止
2. 容器宕机期间无文件变更日志。窗口期内发生的篡改无法溯源
3. 所有校验基线存在于容器文件系统内。环境重置 = 基线归零
4. 心跳、巡检、大盘全部在同一运行时环境内。没有外部第三方监控

## 恢复时能做什么
- 对比 checksum 基线（如果基线文件幸存）
- 检查 Git log 时间线断层
- 对比 cron 配置快照
- 冷备份可用于恢复基线

## 不能做什么
- 无法在宕机期间检测篡改
- 无法在 gateway 挂掉时触发外部告警
- 无法防止环境被整体重置

## 应对策略
- 冷备份每周更新（tar.gz）
- Git push 每周至少 1 次（如有 remote）
- 大盘恢复时自动执行全量对比
