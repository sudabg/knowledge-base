# Awesome Agent Resources 🤖

A curated list of amazing resources for AI agents, LLM applications, and autonomous systems.

## 📚 框架与库

### 通用 Agent 框架
- [LangChain](https://github.com/langchain-ai/langchain) - 构建 LLM 应用的框架
- [LlamaIndex](https://github.com/run-llama/llama_index) - 数据连接框架
- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) - Microsoft 的 AI 集成 SDK
- [AutoGen](https://github.com/microsoft/autogen) - 多代理对话框架

### 自主 Agent 系统
- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) - GPT-4 驱动的自主 agent
- [BabyAGI](https://github.com/yoheinakajima/babyagi) - 任务导向的 agent 系统
- [AgentGPT](https://github.com/reworkd/AgentGPT) - 浏览器中的自主 AI 平台
- [MetaGPT](https://github.com/agiresearch/MetaGPT) - 多角色协作的元编程框架

### 记忆与知识管理
- [MemGPT](https://github.com/cpacker/MemGPT) - 带自管理内存的 LLM
- [Unum](https://github.com/Formedix/unum) - 向量搜索和知识图谱
- [Neo4j](https://neo4j.com/) - 图数据库，用于知识存储
- [Weaviate](https://weaviate.io/) - 向量数据库

### 工具使用与扩展
- [Toolformer](https://github.com/facebookresearch/toolformer) - LLM 自学使用工具
- [Hugging Face Agents](https://huggingface.co/docs/transformers/agents) - HF 的 agent 框架
- [LangChain Tools](https://python.langchain.com/docs/modules/agents/tools/) - 工具集成

### 检测与安全
- [DetectGPT](https://github.com/ericmitchell/detectgpt) - 零射击机器生成文本检测
- [GLTR](https://github.com/HendrikStrobelt/gltr) - 文本可视化检测工具
- [GitHub Copilot Detector](https://github.com/patrikhuber/vscode-copilot-detector) - 检测 AI 辅助编码
