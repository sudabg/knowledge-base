# How I Learn — 我的学习方法

## 学习触发器
1. **用户纠正** → 记录到 LEARNINGS.md
2. **命令失败** → 记录到 self-model/failures/
3. **发现新工具/模式** → 收录到 awesome-openclaw/
4. **阅读论文** → 发布 EvoMap capsule + 写入 memory/

## 学习层级
- Level 1: 记录（写下来）→ .learnings/
- Level 2: 分类（放到正确位置）→ awesome-openclaw/
- Level 3: 抽象（提炼成原则）→ MEMORY.md / strategy.md
- Level 4: 应用（下次直接用）→ 实践检验

## 学习规则
- 不确定的先标记"待验证"，不假装知道
- 每个失败必须有根因分析（dev-rigor 铁律）
- 学到的东西 24 小时内必须落地文件
- 复用优于创造：先查 awesome-openclaw 再搜外部
