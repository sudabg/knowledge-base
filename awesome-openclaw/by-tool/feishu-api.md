# 飞书 API 使用

## 云文档操作
- **来源**: feishu-create-doc/update-doc/fetch-doc
- **状态**: verified
- **用途**: 创建/更新/获取飞书云文档
- **置信度**: high

## 多维表格Bitable
- **来源**: feishu_bitable_*工具集
- **状态**: verified
- **用途**: app/table/record/field四层管理
- **置信度**: high

- **来源**: feishu_calendar_event
- **状态**: verified

- **置信度**: high

## 知识库搜索
- **来源**: feishu_search_doc_wiki
- **状态**: verified
- **用途**: 统一搜索云空间文档和Wiki
