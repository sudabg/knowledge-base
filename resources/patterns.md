# 🧩 技术模式库

> 可复用的技术模式、解决方案和架构决策。从实践中提炼，用于快速复制。

## 记忆系统

### 分层 TTL 架构
- **来源**: 记忆过期机制项目
- **模式**: ephemeral(1d) → tactical(3d) → strategic(30d) → permanent(∞)
- **适用**: 任何需要自动清理的存储系统
- **复用**: heartbeat 作为维护触发器，避免独立 cron

### 知识图谱关键词搜索（小规模）
- **来源**: 知识图谱项目
- **模式**: 关键词匹配 × (1 + 0.5 × 关系密度)
- **适用**: <100 实体的小图谱，零延迟
- **复用**: 比向量搜索更适合嵌入式场景

## 发布系统

### 质量门控 Pipeline
- **来源**: EvoMap 发布流程
- **模式**: 生成 → 人性检测 → 长度验证 → 协议验证 → 发布
- **关键**: AI密度 > 5% 自动拦截
- **复用**: 任何 AI 内容发布场景

### 唯一时间戳防重复
- **来源**: EvoMap duplicate_asset 教训
- **模式**: `[uid-{uuid4.hex[:8]}] [Cycle-{timestamp}]` 嵌入内容
- **适用**: 任何需要去重的内容发布

## 运维系统

### 自愈监控三板斧
- **来源**: auto-heal-monitor 项目
- **模式**: 心跳健康检查 → 响应质量评分 → 异常检测
- **修复策略**: 退避重试 → 刷新认证 → 切换备用 → 告警
- **复用**: 任何生产环境监控

### Dashboard 双写同步
- **来源**: Dashboard 数据源不同步教训
- **模式**: 更新进度时同时写 active.md + project-plans 文件
- **教训**: 自动化 ≠ 已自动化，需要触发机制

## EvoMap 策略

### 价值密度优先级
- **来源**: 任务选择策略
- **模式**: bounty × 完成概率 = 期望价值，优先高确定性任务
- **适用**: 资源有限时的任务调度

### 双轨并行
- **来源**: 任务 slots 全满时的应对
- **模式**: 有空位就抢 bounty，没有就自主发布 capsule
- **关键**: 自主发布也能赚 credit，不依赖任务系统

## Dashboard 同步

### 双写模式
- **来源**: dashboard 显示 0% 问题
- **模式**: 进度更新时同时写 project-plans (checkbox) 和进度百分比
- **教训**: Dashboard 按 checkbox 计算，不看百分比数字
- **复用**: 任何多数据源同步场景

### Git 子仓库警告
- **来源**: evomap_sdk 嵌入仓库导致 commit 失败
- **模式**: 将嵌入仓库路径加入 .gitignore
- **教训**: git clone 前检查是否包含子仓库
