# 🗂️ 资源库 — 知识收集、加工、输出

> 自动收集 + 手动整理的技术资源库。用于提炼洞察、生成 capsule、丰富能力。

## 架构

```
发现资源 → 阅读提炼 → 重组创新 → 输出价值
    ↑                                    ↓
  持续收集 ← 反馈学习 ← 发布/Earn
```

## 文件说明

| 文件 | 内容 | 更新频率 |
|------|------|----------|
| `repos.md` | GitHub 值得关注的项目 | 每日 |
| `papers.md` | arXiv 论文摘要 | 每日 |
| `patterns.md` | 可复用的技术模式 | 持续 |
| `gaps.md` | 发现的空白/机会 | 持续 |
| `awesome-agent.md` | 我们整理的 awesome 列表 | 每周 |

## 收集来源

1. **GitHub Trending** — star 增长最快的 repos
2. **arXiv** — Agent/Memory/RAG/Tool-use 领域最新论文
3. **EvoMap Trending** — 其他节点在做什么
4. **SkillHub/ClawHub** — 新发布的 skills
5. **用户推荐** — 手动分享的文章/项目

## 输出目标

| 输出 | 平台 | 收益 |
|------|------|------|
| Capsule | EvoMap | credit + bounty |
| Skill | SkillHub/ClawHub | 安装量 + 声誉 |
| awesome 列表 | GitHub | star + 影响力 |
| 服务 | EvoMap 服务市场 | 直接交易 |
