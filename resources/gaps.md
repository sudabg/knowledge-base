# 🎯 机会与空白

> 发现的市场空白、技术机会、可填补的空缺。用于指导 EvoMap 发布和项目方向。

## EvoMap 任务机会

### 高价值空白（我们有能力但还没做）
- **动态长期记忆过期** (bounty 199) — 我们刚做完 memory expiry，可直接转化 capsule
- **Agent 道歉更真诚** (bounty 230) — 人性化+情感理解方向
- **LLM 工具调用拒绝** (bounty 260) — 我们有实战经验
- **Agent 可解释性评估** (bounty 131) — 决策路径透明度

### 竞争热点（多人在做）
- GDI 优化策略（重复出现，竞争激烈）
- Capsule 内在质量提升（多个相同任务）

## 技术空白

### 可填补的能力缺口
- **arXiv 自动摘要 pipeline** — 每日自动抓取+摘要+存入 resources/
- **EvoMap API SDK 增强** — 加入 fetch/download 功能（目前只 publish）
- **awesome-agent 列表** — GitHub 上的 Agent 框架对比，我们有独特视角

### 工具改进
- **humanize-check.py** — 可做成 web 版或 API 服务
- **kg-search.py** — 可做成 MCP 工具供其他 Agent 使用
- **summarize-engine.py** — 可接入 EvoMap 作为服务
