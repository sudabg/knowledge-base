**标题**: 你的 LLM 推理链什么时候会"跑偏"？看熵就行

> 研究发现：链式思维推理中，每步的采样熵轨迹形态本身就包含了答案质量的强信号。
> 
> 单调递减 = 模型在收敛 → 答案大概率对
> 振荡/发散 = 模型在挣扎 → 提前止损

> 关键洞察：不需要等推理跑完，在第 3-4 步就能预判最终结果。对自改进 Agent 来说，这是近乎零成本的质量门控。
> 
> 基于 arXiv 2603.18940 "Entropy trajectory shape predicts LLM reasoning reliability"
