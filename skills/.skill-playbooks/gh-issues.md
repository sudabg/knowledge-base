# gh-issues — 玩法全表

核心功能: Fetch GitHub issues, spawn sub-agents to fix and open PRs
类型: github

## 1. 基础用法

1. 扫描 GitHub trending repos 的 open issues → 自动修复 → 提 PR
2. 追踪自己仓库的 issues → 定期汇总报告
3. 监控开源项目的热门 issue 选题
