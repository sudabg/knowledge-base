> 分析日期：2026-03-24 | 任务：S-29

## 1. CraniMem（2603.15642）— 颅骨启发的门控有限记忆模型

### 核心创新
CraniMem 借鉴人类颅骨结构（硬脑膜、蛛网膜、软脑膜三层保护），为 LLM 记忆系统设计了三层门控机制：

- **硬脑膜层（Dura Gate）**：最外层过滤，基于相关性阈值快速拒绝无关信息，减少后续处理负担
- **蛛网膜层（Arachnoid Gate）**：中间层语义分析，使用注意力机制评估信息与已有记忆的关联度
- **软脑膜层（Pia Gate）**：最内层精细合并，对通过前两层的信息执行写入或更新操作

### 与我当前架构的关联
我的记忆系统（MEMORY.md 分层 + memory/*.md）实际上是人工版的 CraniMem：
- MEMORY.md（路由器）= 硬脑膜层（快速路由/过滤）
- memory/active.md = 蛛网膜层（相关性评估）
- memory/archive.md = 软脑膜层（精细存储）

**差距**：我的系统缺少自动化门控——目前靠手动整理。CraniMem 的门控机制可作为自动记忆管理的参考。

### 可借鉴的设计
1. **遗忘门控**：W(t) = e^(-λt) × relevance_score，同时考虑时间和相关性
2. **合并决策树**：exact match → semantic merge → append，与我在 03-23 的 capsule 设计一致
3. **审计追踪**：每次合并记录 before/after/diff，用于调试幻觉

## 2. AgentIR（2603.04384）— 推理感知检索

### 核心创新
传统 RAG 检索不考虑 Agent 的推理状态，AgentIR 提出"推理感知检索"：
- Agent 在推理过程中动态生成检索需求（而非预设 query）
- 检索结果根据当前推理步骤的上下文重新排序
- 支持多轮检索：第 1 轮检索结果可能触发第 2 轮更精确的检索

### 与飞书知识库搜索的关联
当前飞书搜索（feishu_search_doc_wiki）是静态关键词匹配。如果集成 AgentIR：
- 用户问"昨天项目进度"→ 第 1 轮搜"项目进度"→ 发现是 03-23 → 第 2 轮搜"2026-03-23 完成"
- 推理链驱动检索，结果更精准

### 实施建议
1. 在 `feishu_search_doc_wiki` 后增加推理步骤：分析搜索结果，生成二次检索 query
2. 使用 LLM 评估搜索结果与用户意图的匹配度
3. 不匹配时自动 refine query 重搜

## 总结

两篇论文分别解决 Agent 的两个核心问题：
- **CraniMem**：如何高效管理长期记忆（写入/更新/遗忘）
- **AgentIR**：如何在推理过程中精准检索信息

两者结合可以构建一个"写时智能合并 + 读时推理驱动检索"的完整记忆系统。
