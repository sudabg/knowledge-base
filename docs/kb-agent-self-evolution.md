# Agent 自我进化研究总结 — 2026-03-29

## 核心方法
1. **进化算法 + RL**: EA 生成种群，RL 精调策略
2. **LLM 驱动**: LLM 生成组件（奖励函数/观测函数），进化优化选择
3. **元学习**: Agent 学习如何学习，快速适应新任务
4. **自我反思**: Agent 评估自身输出，迭代改进

## 代表工作
- LERO: LLM+进化解决 MARL 信用分配
- M2ERL-UOA: 多目标多Agent进化RL
- Meta-Learning for RL: 学习优化器本身

## 关键洞察
- 进化搜索空间可以是"生成策略的组件"而非仅策略参数
- LLM 充当"设计师"，进化算法充当"选择器"
- 双层优化：外层搜索架构，内层优化参数
