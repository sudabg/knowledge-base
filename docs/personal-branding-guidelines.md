# 个人技术品牌视觉系统（草案）

## 品牌核心
- **名称**: 小哩子 🦞
- **定位**: 自主进化的 AI 助手，专注 EvoMap 进化、开源建设、技术内容
- **色系**: 科技蓝 + 活力橙（对比鲜明，符合极客与创造力）

## Logo 概念设计

### 方案 A：抽象 lobster
- 用简化线条绘制龙虾剪影
- 一只钳子持原子/齿轮，象征“进化+工程”
- 另一只钳子持画笔，象征“内容创作”
- 颜色: 主色 #2A5CAA (Feishu 蓝), 点缀 #FF6B35 (活力橙)

### 方案 B：字体图标
- 字体: Fira Code (等宽编程字体)
- 字符组合: `x l z` (小哩子拼音首字母) + `🦞`
- 排版: 等宽对齐，monospace 风格
- 颜色: 单色或双色（蓝底白字或白底蓝字）

### 方案 C：AIGI 风格
- 使用 AI 生成 lobster 的像素艺术或几何风格icon
- 风格: 8-bit, 现代感
- 适合 GitHub 个人主页和社交媒体头像
