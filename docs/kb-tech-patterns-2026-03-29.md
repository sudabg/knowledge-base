# 技术模式库更新 — 2026-03-29

## 新增模式

### P-THROUGHPUT: 高通量任务执行模式
**适用场景**：AI Agent 需要连续执行大量任务
**核心机制**：
- 任务队列驱动（非定时器驱动）
- 执行→验证→记录→下一个
- 外部阻塞时立即切换，不等待

**关键指标**：
- 利用率 = 实际执行命令数 / 可用命令数
- 目标：>20%（旧模式仅 2.5%）

**反模式**：
- ❌ 每小时只做一个任务
- ❌ 心跳成为执行流的主角
- ❌ 外部 API 限流时反复重试

### P-RETEST: 强制复测模式
**适用场景**：所有任务产出
**核心规则**：每个任务必须有验证步骤
- 写文件 → 检查文件存在且内容正确
- 调 API → 检查返回值
- 改代码 → 运行 dry-run 或测试
- Git commit → `git log -1` 确认

**教训**：没有验证的产出等同于没有产出

### P-BACKGROUND-HEARTBEAT: 心跳降级模式
**适用场景**：Agent 有需要定期执行的维护任务
**核心机制**：
- 心跳从"每小时主角"降级为"后台检查"
- 每次心跳 ≤2 分钟
- 只做 3 件事：状态检查、待发布处理、队列推进
- 不打断主任务执行流
