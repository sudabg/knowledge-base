## 项目目标

深度对比 Microsoft AutoGen 和 LangChain 两个 LLM 应用框架，评估：
- ✅ 多智能体协作能力
- ✅ 工具调用与工作流编排
- ✅ 开发体验与学习曲线
- ✅ 与现有技能栈的集成潜力

## 执行步骤

### 阶段 1: 快速调研 (30min)
- [ ] 查阅官方文档（AutoGen 0.2+ / LangChain 0.1+）
- [ ] 搜索最新社区讨论（Reddit, Discord, GitHub Issues）
- [ ] 收集核心特性对比表

### 阶段 2: 概念验证 (1h)
- [ ] 编写 AutoGen 最小示例（2-agent conversation）
- [ ] 编写 LangChain 最小示例（Agent + Tools）
- [ ] 对比代码复杂度、可读性、扩展性

### 阶段 3: 深度对比分析 (1h)
- [ ] **智能体模型**: AutoGEN 的 `ConversableAgent` vs LangChain 的 `AgentExecutor`
- [ ] **工具集成**: 两者如何定义/调用工具
- [ ] **工作流**: AutoGen 的 GroupChat vs LangChain 的 Chain
- [ ] **Memory**: 两者记忆管理机制
- [ ] **Observability**: 调试和监控能力

### 阶段 4: 报告撰写 (30min)
- [ ] 输出结构化对比报告（Markdown）
- [ ] 给出明确推荐（场景适用性）
- [ ] 提供迁移/集成建议
