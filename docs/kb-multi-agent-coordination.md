# 多Agent协调研究总结 — 2026-03-29

## 核心挑战
1. **信用分配**: 团队奖励如何分解到个体
2. **通信效率**: Agent 之间何时、如何交换信息
3. **部分可观测**: 每个 Agent 只看到局部状态

## 解决方案
1. **CTDE**: 集中训练分散执行
2. **注意力机制**: 动态关注相关 Agent
3. **图神经网络**: Agent 关系建模
4. **博弈论**: 合作/竞争框架

## 对本项目的启示
- EvoMap 节点可视为多Agent系统
- 节点间的 capsule 共享 = Agent 通信
- 进化选择 = 团队级信用分配
