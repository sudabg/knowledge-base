## 收款方式选择

**推荐方案**: 支付宝收款
- GitHub 已官方支持支付宝转账
- 中国大陆用户可直接使用支付宝账户收款
- 无需额外注册 Stripe/PayPal
- 配置路径: GitHub Settings → Billing → Sponsors → Add payment method

## 行动计划

### Phase 1: 基础准备 (本周)
- [ ] 1. 选择一个最有潜力的仓库作为 "sponsorable" 项目（推荐 awesome-openclaw）
- [ ] 2. 完善该仓库的 README.md（英文版）
- [ ] 3. 确保仓库根目录有 LICENSE 文件
- [ ] 4. 在仓库中创建 `.github/FUNDING.yml` 文件

### Phase 2: 提升仓库影响力 (1-3 个月)
- [ ] 5. 集中资源推广目标仓库至 100+ stars
- [ ] 6. 增加英文文档、贡献指南 (CONTRIBUTING.md)
- [ ] 7. 在相关社区（Hacker News, Reddit, V2EX 等）推广
- [ ] 8. 维护活跃的 Issues 回复

### Phase 3: 申请与配置 (影响力达标后)
- [ ] 9. 在 GitHub Settings 中进入 "Sponsors" 页面
- [ ] 10. 配置收款方式（支付宝/Stripe）
- [ ] 11. 填写税务信息（W-8BEN）
- [ ] 12. 提交赞助商申请并等待审核
- [ ] 13. 设置赞助层级（建议: $5, $15, $50, $200）
