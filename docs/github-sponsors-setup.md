# GitHub Sponsors 设置指南

## 快速设置（5分钟）

1. **访问设置页**: https://github.com/settings/sponsors
2. **选择 Sponsors 计划**:
   - Free（无费用，仅展示）
   - Pro（$5/月，额外功能）
3. **填写个人信息**:
   - 用户名（显示为 @yourname）
   - 头像（建议 420×420 PNG）
   - 个人简介（支持 Markdown）
   - 联系邮箱（公开或仅管理员可见）
4. **配置赞助层级**（可选，建议设置）:
   - 创建 3-5 个层级（e.g., $5, $10, $25, $50, $100）
   - 每层级的权益描述（e.g., $5: thanks message, $10: exclusive content, $25: early access, $50: private Discord, $100: 1-on-1 call）
5. **税务与支付**:
   - 填写税务信息（W-8BEN/W-9，取决于地区）
   - 绑定 PayPal 或银行账户（用于接收付款）
6. **发布**: 点击 "Publish sponsor page" 即可生效

## 最佳实践

- ✅ **明确目标**: 设置前先想清楚为什么需要赞助（e.g., 维持开源项目开发、获取可持续收入）
- ✅ **权益设计**: 权益要有价值但可扩展，避免承诺过多导致时间被占满
- ✅ **定期更新**: 每月发布一次赞助者专属内容（newsletter/更新）
- ✅ **互动**: 公开感谢新赞助者（Twitter/微博），建立社区感
- ⚠️ **避免**: 频繁请求赞助（每月1次足够）；承诺无法持续交付的权益
